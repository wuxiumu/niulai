## 〇、一页看懂项目

| 项 | 现状 |
|----|------|
| 产品 | 限时搏杀型股市模拟：养牛 → 牛运值 → 炒股 → 冲榜 |
| 主入口 | `niulai-game.html` + `static/js/*` · `static/css/*`（ES Module） |
| 周边页 | `leaderboard.html`（用户榜/分享/PK）、`admin/`（后台）、`index.php`（落地导览） |
| 服务端 | `api/`：Redis 排行榜 + SQLite 分享/PK |
| 启动 | **必须** HTTP：`php -S 127.0.0.1:8800` → `http://127.0.0.1:8800/niulai-game.html`（`file://` 不可用） |
| 全网榜 | 需 PHP + Redis；不可用时静默回退本机 `localStorage` |

### 目录对照

```
niulai/
├── index.php / niulai-game.html / leaderboard.html   ← 页面
├── static/{css,js,vendor,img,manifest.json}          ← 静态资源 + Logo
├── includes/seo.php · robots.txt · sitemap.php       ← SEO/GEO
├── admin/ · api/                                     ← 后台与接口
└── doc/                                              ← 路线图 / SEO 说明
```
