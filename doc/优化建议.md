## 二、这个游戏是怎么运转的（3 分钟看懂）

整个游戏就一个文件 `niulai-game.html`，从上到下分三块：

```
┌─────────────────────────────────────┐
│  <style>  ...  </style>             │  ← CSS：长什么样（颜色、字号、动画）
├─────────────────────────────────────┤
│  <body> 里的 HTML 标签               │  ← 骨架：界面上有哪些东西（按钮、卡片）
├─────────────────────────────────────┤
│  <script>  ...  </script>           │  ← JS：怎么玩（逻辑、数值、存档）
└─────────────────────────────────────┘
```

游戏的心脏是一个**定时循环**，代码里叫 `gameTick`：

```
每 0.2 秒做一次：
  ① 养牛产出牛运值（牛越多产得越快）
  ② 推进行情进度条
  ③ 每满 15 秒 → 结算一次股票盈亏 → 随机换行情（牛市/熊市/震荡）
  ④ 刷新屏幕上的数字
```

想改任何数值，都在 `<script>` 部分的最上方，有中文注释，比如：

- `STOCK_DEFS`：5 种股票的**价格和各行情下的收益**
- `CYCLE_TIME = 15000`：行情周期，单位毫秒（15000 = 15 秒）
- `ACHV_DEFS`：10 个成就的**解锁条件**
- `EVENTS`：8 种随机事件的**文案和效果**

## 三、优化建议清单（按优先级排序）

### 🔴 P0 — 玩法缺口：股票只能买、不能卖

**问题**：现在买入的股票永远拿在手里。熊市来了想抛掉牛股？做不到。想卖掉熊股换牛股？也做不到。
**为什么重要**：炒股游戏没有"卖"，策略性少了一半——"什么时候跑"才是炒股的灵魂。
**怎么改**：
1. 在 `state.stocks` 记录买入均价；
2. 股票卡片上加一个"卖出"按钮，按当前行情的价格卖出（比如牛市卖出价 = 成本 × 1.5，熊市 = 成本 × 0.7）；
3. 搜索代码里的 `renderStocks` 函数，在"买入"按钮旁边加"卖出"按钮即可。

### 🟠 P1 — 性能：每 0.2 秒全量刷新界面

**问题**：`setInterval(gameTick, 200)` 每 0.2 秒把所有数字、进度条**全部重画一遍**，哪怕数字根本没变。手机上会更费电、发热。
**为什么重要**：挂机游戏一挂几小时，省电就是体验。
**怎么改**（两种，任选）：
- 简单版：把 `200` 改成 `500`（半秒刷一次，肉眼几乎无感）；
- 进阶版：在 `updateUI` 里先比较新旧值，变了才更新对应元素。

### 🟠 P1 — 放置游戏标配：离线收益

**问题**：关掉页面再打开，中间几小时的牛运值一分都没有——这违背了"放置游戏"的核心承诺。
**为什么重要**：放置游戏的爽点就是"睡一觉起来收菜"。
**怎么改**：
1. 存档时多存一个时间戳 `state.lastSaveTime = Date.now()`；
2. 打开游戏时算出离开了多少秒，按 `秒数 × 牛数 × 0.3` 补发牛运值（建议封顶 2 小时，防止刷收益）；
3. 补发时弹个提示："你离开了 X 小时，牛牛们为你攒了 Y 牛运值！"

### 🟡 P2 — 存档会丢：加导出/导入

**问题**：存档存在浏览器 localStorage 里，清理浏览器数据、换浏览器、换设备都会丢档。
**怎么改**：在设置弹窗里加两个按钮：
- "导出存档"：把存档 JSON 转成 Base64 文本，复制保存到备忘录；
- "导入存档"：粘贴文本恢复。
搜索代码里的 `save()` 和 `localStorage.getItem` 就是读写存档的地方。

### 🟡 P2 — 没有音效

**问题**：买入、结算、触发"牛来"彩蛋时完全静音，爽感打折。
**怎么改**：用浏览器自带的 Web Audio API 生成简单音效（不需要音频文件）：
- 买入：短促的"叮"（高频正弦波 0.1 秒）；
- 牛市结算：上扬的双音；
- 牛来彩蛋：低音鼓点 + 上扬音阶。
记得在设置里加一个**静音开关**（默认静音也合规，浏览器要求用户交互后才能出声）。

### 🟢 P3 — 新手引导

**问题**：第一次进游戏，小白不知道先干嘛。
**怎么改**：首次进入时（判断 `state.cycleCount === 0`）分三步高亮提示：
1. "👆 先点这只牛牛，攒牛运值"（让牛牛闪烁）；
2. "👇 有 100 牛币了？买入你的第一支牛股"（高亮买入按钮）；
3. "⏱️ 每 15 秒结算一次，红色牛市赚翻倍！"（高亮行情指示器）。

### 🟢 P3 — 加到手机主屏幕（PWA）

**问题**：每次玩都要找到这个文件/网址。
**怎么改**：加一个 `manifest.json` 和图标，iPhone 上 Safari 分享 → "添加到主屏幕"，就能像 App 一样点开就玩。

## 四、数值平衡速查表（自己动手调）

觉得游戏太难或太简单？改这些地方就行：

| 我想要… | 改哪里 | 怎么改 |
|---------|--------|--------|
| 行情变化更快/更慢 | `CYCLE_TIME = 15000` | 改小更快（如 `8000`），改大更慢 |
| 牛运值攒得更快 | `state.cattle * 0.3` | 把 `0.3` 调大 |
| 牛股更赚钱 | `STOCK_DEFS` 里牛股那行的 `bull: 60` | 调大这个数 |
| 熊市更惨/更温和 | 各股票的 `bear: -15` | 负数越大亏越多 |
| 牛来彩蛋更常出现 | `Math.random() < 0.08` | `0.08` 改成 `0.15` 就是 15% 几率 |
| 许愿更灵 | `Math.random() < 0.8` | `0.8` 改成 `0.95` |
| 初始资金更多 | `bullCoins: 100` | 改成你想要的数 |
| 牛市出现更频繁 | `rollMarket` 里的 `r < 0.4` | `0.4` 调大牛市概率就高 |

> ⚠️ 改数值前建议先复制一份文件备份，改坏了还能恢复。

## 五、改完怎么验证

1. 保存文件；
2. 浏览器里**强制刷新**（Mac：`Cmd + Shift + R`，Windows：`Ctrl + F5`）——普通刷新可能用缓存的旧文件；
3. 打开浏览器开发者工具（按 `F12`）看 Console 有没有红色报错，有报错就把报错内容发给 AI 问。
